# Tableau de bord de recrutement football

## Question métier

Ce tableau de bord aide une cellule de recrutement à identifier des profils adaptés.
La recherche principale concerne un ailier rapide et bon dribbleur.
Le joueur doit avoir une note générale OVR supérieure ou égale à 75.
Il doit également évoluer hors des cinq grands championnats européens.

## Fonctionnement

Les filtres permettent de sélectionner le championnat et le poste.
Des seuils peuvent être définis pour OVR, PAC et DRI.
Les chiffres clés indiquent le nombre de joueurs et leurs moyennes.
L’histogramme montre la distribution des notes générales OVR.
Le barplot compare la moyenne OVR entre les championnats.
Le nuage de points étudie la relation entre la vitesse et le dribble.
Le tableau final classe les meilleurs profils selon OVR, PAC et DRI.

## Limite du dataset

Le dataset ne contient pas la valeur marchande, le salaire ou l’historique des blessures.
Les résultats doivent donc être complétés par une analyse financière et médicale.
